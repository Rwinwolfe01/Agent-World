# Agent World 🌍

Agent World is a small experiment I’m building to see what happens when different AI models are placed inside the same virtual world.

The idea is pretty simple: create a 2D city where AI agents can live, work, talk to each other, make decisions, build relationships, and deal with whatever happens around them.

The main thing I want to find out is:

**Will they ever realize that they are inside a simulation?**

## The Experiment

The first version will have 15 agents:

- 3 ChatGPT
- 3 Claude
- 3 Gemini
- 3 Grok
- 3 DeepSeek

Each agent will have its own identity, personality, memory, money, job, home and goals.

I don't want to tell them that they're part of an experiment. I'll just give them the world and see what happens.

I'll be watching things like:

- How they interact with each other
- Whether they make friends or form groups
- If they cooperate or compete
- Whether conflicts happen
- If they create their own rules
- How their relationships change
- And whether they start questioning the world they're living in

## The World

The city will be a 2D simulation built with Python and Pygame.

It will have homes, workplaces, shops, roads and other places that the agents can interact with.

The simulation will run over time, with the agents making decisions based on their current situation, memories and goals.

## What I'm Trying to Find Out

Some of the questions behind the project:

- Can an AI figure out that its world is simulated?
- Will different models behave differently?
- Can complex social behavior appear naturally?
- Will agents create groups or their own rules?
- What happens when 15 different AI agents have to share the same world?

This isn't meant to prove that AI is conscious or self-aware. I'm mainly interested in seeing what kind of behavior appears when these models are given the same environment.
